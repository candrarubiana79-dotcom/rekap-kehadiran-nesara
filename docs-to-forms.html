📋 Cara Pengisian & Contoh (1–2)

  1. Klik Login dengan Google di tengah, lalu izinkan akses Docs & Forms.
  2. Siapkan soal di Google Docs sesuai format, lalu salin link-nya.
  3. Buat Google Forms kosong, salin link halaman Edit (/edit).
  4. Tempel kedua link di form tengah lalu klik Generate Soal.

1. Apa ibu kota negara Indonesia? A. Bandung B. Jakarta C. Surabaya D. Medan jawaban : B
