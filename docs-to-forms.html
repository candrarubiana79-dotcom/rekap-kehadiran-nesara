📖 Petunjuk Penggunaan & Format Soal

1. Cara Pengisian

  1. Klik tombol Login dengan Google, lalu centang izin akses untuk membaca Google Docs dan mengisi Google Forms.
  2. Siapkan file Google Docs berisi daftar soal sesuai contoh format di bawah, lalu salin URL dokumen tersebut.
  3. Buat file Google Forms baru (kosong), salin URL dari halaman Edit (berakhiran /edit, bukan link kirim/responder).
  4. Tempel kedua link ke kolom formulir, pilih Mode Pembagian Poin Nilai, lalu klik Generate Soal ke Forms.

2. Contoh Format Soal (Biasa, Mudah, Sulit, Poin, & Gambar)

Salin contoh ini ke Google Docs Anda: 
1. Apa ibu kota negara Indonesia?
A. Bandung
B. Jakarta
C. Surabaya
D. Medan
jawaban : B

2. [mudah] Lambang sila pertama Pancasila adalah...
A. Rantai
B. Pohon Beringin
C. Bintang
D. Kepala Banteng
jawaban : C

3. [sulit] Berdasarkan analisis dampak perubahan iklim global terhadap wilayah pesisir, strategi adaptasi manakah yang paling berkelanjutan?
A. Membangun tanggul beton di seluruh garis pantai
B. Rehabilitasi ekosistem mangrove terpadu dengan tambak silvofishery
C. Merelokasi seluruh penduduk pesisir ke dataran tinggi
D. Mengimpor seluruh kebutuhan pangan pokok
jawaban : B

4. [25 poin] Planet manakah yang dijuluki Planet Merah?
A. Venus
B. Mars
C. Jupiter
D. Bumi
jawaban : B

5. Perhatikan gambar organ pernapasan di bawah ini!
[Sisipkan / Paste Gambar JPG atau PNG langsung di baris ini]
Bagian yang ditunjuk oleh huruf X berfungsi untuk...
A. Menyaring udara kotor
B. Pertukaran oksigen dan karbon dioksida
C. Mengatur suhu udara masuk
D. Menghasilkan suara
jawaban : B

3. Aturan Format, Gambar & Poin

  • Soal Biasa & Tag Bobot: Nomor 1 adalah soal biasa (bobot dideteksi otomatis). Nomor 2–4 memakai tag opsional [mudah], [sulit], atau [25 poin] untuk mengunci bobot/nilai soal tertentu.
  • Soal Bergambar (Nomor 5): Sisipkan gambar (format JPG/PNG/GIF, maks. 2 MB) langsung di bawah pertanyaan atau di samping opsi A.–E.. Hindari fitur Insert > Drawing agar gambar terbaca otomatis.
  • Kunci Jawaban: Tulis di baris terakhir tiap soal dengan format jawaban : B (tidak peka huruf besar/kecil). Untuk jawaban ganda, pisahkan dengan koma seperti jawaban : A, C.
  • Total 100 Poin Otomatis: Sistem otomatis membagi sisa poin ke seluruh soal biasa, mudah, dan sulit hingga jumlah nilainya pas 100 poin.
