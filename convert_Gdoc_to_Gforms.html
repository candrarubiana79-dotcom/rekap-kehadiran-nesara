Docs ke Google Forms

Konversi soal dari Google Docs ke Google Forms secara otomatis dengan pembagian bobot nilai cerdas.

Status: Belum terhubung ke Google
Sistem menganalisis panjang soal & kata kunci HOTS untuk membagi total 100 poin secara proporsional. Tag [25 poin] atau [sulit] di Docs tetap diprioritaskan.

📖 Petunjuk Penggunaan & Format Soal

1. Cara Pengisian

  1. Klik tombol Login dengan Google di atas, lalu centang izin akses untuk membaca Google Docs dan mengisi Google Forms.
  2. Siapkan file Google Docs berisi daftar soal yang ditulis sesuai format di bawah, lalu salin URL/link dokumen tersebut.
  3. Buat file Google Forms baru (kosong), pastikan Anda menyalin URL dari halaman Edit (yang berakhiran /edit, bukan link kirim/responder).
  4. Tempel kedua link ke kolom yang tersedia, pilih Mode Pembagian Poin Nilai, lalu klik Generate Soal ke Forms.

2. Contoh Format Penulisan di Google Docs

Salin contoh di bawah ini ke Google Docs Anda: 
1. Apa ibu kota negara Indonesia?
A. Bandung
B. Jakarta
C. Surabaya
D. Medan
jawaban : B

2. [25 poin] Planet manakah yang dijuluki Planet Merah?
A. Venus
B. Mars
C. Jupiter
D. Bumi
jawaban : B

3. [sulit] Berdasarkan analisis dampak perubahan iklim global terhadap wilayah pesisir, strategi adaptasi manakah yang paling berkelanjutan?
A. Membangun tanggul beton di seluruh garis pantai
B. Rehabilitasi ekosistem mangrove terpadu dengan tambak silvofishery
C. Merelokasi seluruh penduduk pesisir ke dataran tinggi
D. Mengimpor seluruh kebutuhan pangan pokok
jawaban : B

3. Aturan Format & Pembagian Poin

  • Nomor & Pilihan Ganda: Awali soal dengan angka (1.) dan opsi dengan huruf A. sampai E. (mendukung huruf besar maupun kecil).
  • Kunci Jawaban: Tulis di baris terakhir tiap soal dengan format jawaban : B (tidak peka huruf besar/kecil). Untuk jawaban lebih dari satu (kotak centang), pisahkan dengan koma seperti jawaban : A, C.
  • Tag Bobot Opsional: Anda bisa menambahkan tag di awal pertanyaan seperti [25 poin] untuk mengunci nilai soal tertentu, atau [mudah], [sedang], [sulit] untuk mengatur tingkat kerumitan secara manual.
  • Total 100 Poin Otomatis: Jika tidak diberi tag manual, sistem akan menghitung panjang kalimat serta kata kunci analisis (HOTS) pada tiap soal dan membagi total nilai hingga pas 100 poin.
